# Frontend Company Skill

A reusable frontend development skill for React + Vite + TypeScript projects.

This skill enforces strict architecture rules for:

- folder structure
- multi-client layouts
- client-specific theming
- access control
- API/service placement
- Redux usage
- UI library discipline (AntD / MUI / Shadcn)

---

## 🚀 Why this exists

Most AI-generated frontend code becomes messy:

- random folders
- mixed UI libraries
- API calls inside components
- hardcoded tenant logic
- inconsistent structure

This skill fixes that by acting as a **rule engine**.

Think of it like:

> “Tally for frontend structure”

---

## 🧠 What this skill does

When used with AI agents (Codex / Claude / Superpowers):

- forces consistent folder structure
- prevents bad architectural decisions
- enforces multi-tenant patterns
- ensures separation of concerns
- standardizes code output
- improves team productivity
